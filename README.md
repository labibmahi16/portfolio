# K.M Mahir Labib — Portfolio

An animated, interactive portfolio built with **React + Vite**.

## Run locally

```bash
npm install
npm run dev
```

## Where to edit

| What                          | Where                                  |
| ----------------------------- | -------------------------------------- |
| All text, links, projects     | `src/data.js`                          |
| Colours & fonts               | top of `src/index.css` (`:root`)       |
| Profile photo                 | `public/images/profile.jpg`            |
| Project screenshots           | `public/images/projects/*.jpg`         |
| Photography gallery           | `public/images/gallery/1.jpg … 6.jpg`  |
| CV (Download CV button)       | `public/KMML_CV.pdf`                   |

## Deploy

Push to GitHub, import the repo on [vercel.com](https://vercel.com) — it auto-detects Vite
(build: `npm run build`, output: `dist`). Every `git push` redeploys.
